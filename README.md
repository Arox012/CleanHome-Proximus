# CleanHome — Proximus Edition

Experimental Android TV launcher for the Technicolor / Proximus UIW4068PXM decoder running Android 12.

## Goals
- Clean, Apple TV-inspired interface designed for a TV remote.
- Discover and launch installed Android TV applications.
- Organize apps into Films & series, Music, Games and Other.
- Provide a direct route back to the Proximus launcher.
- Build debug APKs automatically with GitHub Actions.

## Safety
This project does not require root, modify firmware, disable system packages, or uninstall the Proximus launcher. Compatibility with the operator firmware must be validated on the target decoder before relying on CleanHome as the default HOME app.

## Status
Prototype. Not production-ready until installation, remote navigation, launcher selection and recovery have been tested on the target decoder.
